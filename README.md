# 홈페이지 제작 포트폴리오

크몽 상세페이지 홍보용으로 만든 업종별 반응형 홈페이지 샘플 6종입니다.
모든 사이트는 PC, 태블릿, 모바일 화면에 맞게 자동으로 배치가 바뀌며, 흰색 배경 기반의 라이트 모드로만 제작했습니다.

| 번호 | 업종 | 사이트 | 폴더 | 글꼴 |
| --- | --- | --- | --- | --- |
| 01 | 의류 쇼핑몰 | NOUÉ 누에 | `sites/fashion` | Archivo(와이드) + Pretendard |
| 02 | 병원 | 고른치과의원 | `sites/dental` | Pretendard |
| 03 | 피부관리샵 | 결 스킨 아틀리에 | `sites/skin` | 고운바탕 + Marcellus + Pretendard |
| 04 | 필라테스 | 오크 필라테스 | `sites/pilates` | Bricolage Grotesque + Pretendard |
| 05 | 법률사무소 | 법률사무소 한결 | `sites/law` | Noto Serif KR + Pretendard |
| 06 | 베이커리 카페 | 보늬 베이커리 | `sites/bakery` | 고운돋움 + Young Serif + Pretendard |

`index.html`은 여섯 사이트를 한 번에 보여 주는 포트폴리오 메인 페이지입니다. 각 샘플을 PC 화면과 휴대폰 모양 틀에 넣어 보여 주므로 크몽 상세페이지용 캡처로 쓰기 좋습니다.

## 내 컴퓨터에서 보는 방법

1. 이 저장소 페이지에서 **Code → Download ZIP**을 눌러 내려받습니다.
2. 압축을 풀고 `index.html`을 더블클릭하면 브라우저에서 열립니다.
3. 각 사이트는 `sites/업종/index.html`을 열어도 바로 볼 수 있습니다.

별도 설치나 인터넷 연결 없이 열립니다. 글꼴 파일이 `assets/fonts`에 들어 있어서 어느 컴퓨터에서나 같은 모양으로 보입니다.

## 크몽에 넣을 링크 만들기 (GitHub Pages)

1. 저장소 **Settings → Pages**로 이동합니다.
2. **Branch**에서 이 브랜치를 고르고, 폴더는 `/ (root)`로 둔 뒤 저장합니다.
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소 이름>/` 주소가 생깁니다.

무료 계정은 공개(Public) 저장소에서만 Pages를 쓸 수 있습니다.

## 사진 바꾸기

지금 들어 있는 사진은 레이아웃 확인용 임시 이미지입니다. 각 사이트의 `images` 폴더에 **같은 파일 이름으로 덮어쓰면** 코드 수정 없이 바로 바뀝니다.

- 예: `sites/dental/images/hero.jpg` → 치과 첫 화면 사진
- 가로·세로 비율이 달라도 화면에 맞게 자동으로 잘려 들어갑니다.

## 수정할 때 알아 둘 점

- 상호, 대표자, 사업자등록번호, 주소, 전화번호는 모두 가상의 정보입니다. 실제 고객 사이트로 쓸 때는 반드시 바꿔 주세요.
- 각 사이트 맨 아래의 "포트폴리오용 가상 사이트" 문구는 샘플임을 알리기 위한 것입니다. 실제 납품 시에는 지우면 됩니다.
- 문의·예약 폼은 입력값 확인까지만 동작합니다. 실제로 메일이나 문자로 받으려면 폼 전송 서비스와 연결해야 합니다.
- 치과 사이트의 문구는 의료광고 기준(과장·비교 표현 금지)을, 법률사무소 사이트는 변호사 광고 규정(광고책임변호사 표기)을 고려해 썼습니다.

## 글꼴 라이선스

모든 글꼴은 SIL Open Font License로 배포되어 상업적으로 사용할 수 있습니다. 라이선스 파일은 `assets/fonts/글꼴 이름` 폴더에 함께 들어 있습니다.
